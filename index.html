まだ顔画像がありません

このアプリは data/faces.json と data/faces/ の顔画像を使います。次の手順で用意してください。

  1. npm install
  2. GEMINI_API_KEY=xxx npm run generate -- --count 160
    他のツールで作った画像を使う場合はこの手順は不要です
  3. npm run analyze -- --from .cache/raw
